# SimpleCountdown

A simple timer app for Clash of Clans or any base-building game.

## Summary

Clash of Clans is a well-known base-building game by Supercell Inc., primarily for mobile players. Released in 2012, this game is about attacking and building bases, where you upgrade your armies and defenses as you progress through the contents.\\

One main issue with those that have to juggle between multiple accounts in this game is the ability to manage upgrade timers between multiple accounts. The game does have its own notification system, though, not only does it work for one account per device, it is inconsistent and lacks additional features that would make management much easier and far less time-consuming than it should have been.\\

Several alternatives have some issues that are not totally resolved, including:

* **clash.ninja**: It contains the ability to track multiple timers from multiple accounts. However, it does not have an overview over multiple accounts at once, does not have multiple attention mechanics for different accounts to allow the user to know which should be given attention first. Aside from those, one most crucial issue is it does not contain boosts and recurrent helpers into calculations - it only shows the remaining timer, instead of the actual time left after deducted by helpers and such. The site is not specifically developed for timer tracking, but the overall game instead.
* Many widgets do not support multi-account tracking, nor have details on helpers' cooldowns and resources management, while resource is crucial for future upgrades.

## Main features

The application would have these primary features:

* CRUD: Timers and accounts.
* Sorting and filtering timers by account, village and upgrade types.
* A global view of timers.
* Notifications.
* Additional in-game boosts.
* Importing village export JSON into an existing account.

Additional features are included, but not limited to:

* Low-power mode.
* Resources management.
* Upgrade plan.
* Star Bonus.
* An Android version to continue tracking on the phone.
